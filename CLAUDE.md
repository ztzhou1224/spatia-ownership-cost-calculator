# CLAUDE.md

Guidance for Claude Code in this repository.

- A pilot of Spatia's ownership cost calculator (owner direction 2026-11-18): every input has an estimated default, and the user can
  change any input or set any cost line. The study and its sources: `docs/study.md`.
- Vite + React + TypeScript on ONE Cloudflare Worker (`spatia-ownership-cost`, cost.runspatia.com; owner 2026-11-18: "if you
  need a server use the cloudflare worker"; the subdomain was left to us). Logic in `src/lib/` (pure, tested with vitest), UI in
  `src/App.tsx`, the Worker in `workers/app.ts` (static assets + `/api/lookup`). The site is free, with no login. It records nothing a
  visitor enters, and it shows no privacy notice (owner, 2026-11-19: "Put it back to browser and don't record, get rid of the
  reminder as well"). The calculation runs in the browser. The address is never stored or logged; the lookup answers `no-store`. Secrets `SPATIA_CLIENT_ID` / `SPATIA_CLIENT_SECRET` (a spatia-auth service client, audience
  `geocode`, bound to Home's service user) and `RENTCAST_API_KEY` are Worker secrets only, never in this PUBLIC repo.
- Google Analytics (owner, 2026-11-19: "Let's put every filed change on sentry or google analytics I want to see which field
  user changed most"): Spatia's Tag Manager container `GTM-N3B62N2R` (as Home and Crime), production builds on cost.runspatia.com
  only (`src/lib/analytics.ts`). Events carry the field and the value it changed to (owner, the same day: "And to what number.
  Also recording the value"), never the address or the ZIP: `change_<field>` 1.5 s after the last change of that field with
  `new_value` / `new_value_num` / `default_value`, `reset_<field>`, `set_line_<line>` (the monthly figure typed),
  `reset_line_<line>`, `search_address`, `search_zip`. The page address
  Google gets has no query, and the page no longer writes `?zip=` into the address bar.
- RentCast (owner 2026-11-18): the property record only, through the allowlist in `src/lib/rentcast.ts` (never an owner field,
  the zoning, the APN, the subdivision or the legal description); its facts are labelled RentCast's, never a value of the home.
- A PILOT layer is never published: the data build reads a withheld layer only with `TX_PILOT_PREVIEW=1`, for a local look, and
  that output is never committed. Texas reads `tx_property_tax_rates` (promoted to stable 2026-11-18, `docs/texas-promotion.md`).
- Data tables are GENERATED by `scripts/build-data.ts` from Spatia's data service (`/query`), Census files and Freddie Mac's PMMS.
  Never hand-edit `public/data/**` or `src/data/*.generated.json`. A token comes from spatia-report's `query-token` skill; never ask
  the owner for one.
- Copied from spatia-report (keep them in step, say the commit in the header): `src/lib/energy.ts`,
  `src/data/energy-formula.generated.json`, and the Florida back-test (trimmed into `src/data/fl-tax.generated.json` by the build).
- The rules carried from Spatia Home: a figure with a range only where a back-test measured it; published figures stated as
  published (Treasury's premium is its year's, never scaled); no estimate is called a quote; no figure about the residents of an area.
- Gate before a push: `pnpm test` and `pnpm build`.
- Releases by hand only: *Actions → Cut release → Run workflow* (`.github/workflows/cut-release.yml`; owner 2026-11-19, "A cut
  release button please") tags the branch head `vYYYY.MM.DD` (or the tag typed), creates the GitHub release, builds and deploys the
  Worker with the repository secrets `CLOUDFLARE_ALL_IN_ONE` / `CLOUDFLARE_ACCOUNT_ID`. No workflow runs on a push. This session's
  git proxy refuses a tag push: start the workflow through the GitHub tools (`actions_run_trigger`).
- Talk to the owner in ASD-STE100 Simplified Technical English.
